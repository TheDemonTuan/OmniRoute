# RTK v0.47.0 Benchmark Corpus

This directory is the OmniRoute-owned benchmark corpus for RTK compression. Each case must record input/output bytes, estimated token savings, processing time, eligibility, passthrough status, and semantic-fidelity checks.

Required families: git-diff, ctest, maven, mvnd, phpt, typescript, grep-rg, ls, test runners, Docker, cloud, generic errors, negative detection, and structured JSON.

Do not use upstream RTK savings percentages as OmniRoute benchmark results. Report only measurements generated from this corpus.
